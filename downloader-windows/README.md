# داونلودر لويندوز

نسخة ويندوز من تطبيق «داونلودر»: ألصق أي رابط (فيديو، صورة، صوت)، اختر الجودة، وحمّل.
كل شيء يعمل على جهازك: لا خادم، لا إعلانات، لا تتبّع، لا تحليلات.

| | |
|---|---|
| الملف | `Downloader.exe` (ويندوز 10 / 11، 64-بت) |
| الإصدار | 1.0 |
| التقنية | Go + واجهة ويب داخل نافذة ويندوز أصلية (WebView2) |
| المحرك | [yt-dlp](https://github.com/yt-dlp/yt-dlp) + [FFmpeg](https://ffmpeg.org) + [gallery-dl](https://github.com/mikf/gallery-dl) |

## التشغيل

1. فكّ الملف المضغوط في أي مجلد (مثلاً `C:\Downloader`). يجب أن يبقى مجلد `bin` بجانب `Downloader.exe`.
2. شغّل `Downloader.exe`.
3. **أول تشغيل** يحتاج إنترنت: يُنزَّل محرك التحميل yt-dlp (نحو 18 م.ب) مرة واحدة، مع شريط تقدّم.

**تحذير ويندوز «Windows protected your PC»:** البرنامج غير موقّع بشهادة مدفوعة، فيظهر هذا التحذير عند أول تشغيل.
اضغط **More info** ثم **Run anyway**. وبعض برامج الحماية قد تشتبه به لأنه ينزّل ملفات تنفيذية (yt-dlp)؛ أضفه للاستثناءات إن لزم.

**إن لم تظهر نافذة البرنامج** وفُتحت الواجهة في المتصفح بدلاً منها: جهازك بلا WebView2 (نادر في ويندوز 10 القديم).
البرنامج يعمل كما هو من المتصفح، أو ثبّت «WebView2 Runtime» من موقع مايكروسوفت لتظهر النافذة.

يمكن أيضاً تشغيل `Downloader.exe` وحده بدون مجلد `bin`: عندها ينزّل FFmpeg أيضاً عند أول تشغيل (نحو 140 م.ب).

## المزايا (مطابقة لنسخة أندرويد)

- **الرابط:** لصق من الحافظة، اكتشاف تلقائي للرابط المنسوخ عند فتح البرنامج أو العودة إليه.
- **الجودات:** كل الجودات مرتبة من الأعلى (4K، 1440p، 1080p…) مع الحجم التقريبي، والأعلى محددة افتراضياً. «صوت فقط» MP3/M4A مع العنوان والغلاف.
- **الدمج:** الفيديو والصوت يُدمجان تلقائياً في MP4.
- **القوائم والمنشورات المتعددة:** اختيار العناصر. منشورات الصور عبر gallery-dl بجودتها الأصلية.
- **خيارات الفيديو:** مسار الصوت (الدبلجات)، الترجمة (مدمجة أو ملف SRT، للفيديو المفرد وللقوائم كلها أو فيديوهات معيّنة)، قصّ مقطع.
- **التحميل:** طابور بتحميلات متوازية، نسبة وسرعة ووقت متبقٍّ، إيقاف مؤقت، استكمال، إلغاء، إعادة محاولة.
- **تحميلاتي:** معاينة وتشغيل داخل البرنامج، بحث، فرز، تحديد متعدد، إعادة تسمية، فتح بالبرنامج الافتراضي.
- **السجلّ:** كل رابط حُمّل، مع تنبيه وتأكيد عند محاولة تحميله مرة أخرى.
- **الإعدادات:** الجودة الافتراضية، صيغة الصوت، عدد التحميلات المتوازية، مكان الحفظ، الحفظ التلقائي، تحديث المحرك، الحسابات، مسح الكاش.

## منطق الحفظ

1. الملف بعد التحميل يُخزَّن في مساحة البرنامج (`%LOCALAPPDATA%\Downloader\library`) ويظهر في «تحميلاتي».
2. «حفظ في الجهاز» ينقله إلى مجلد الحفظ ثم يزيله من البرنامج:

   ```
   Downloads\
   └── داونلودر\
       ├── فيديو\      (وملفات الترجمة SRT بجانب الفيديو)
       ├── صوتيات\
       ├── صور\
       └── أخرى\
   ```
3. أي فشل يُبقي الملف في البرنامج كما هو. بدون ضغط «حفظ» لا يُحذف شيء تلقائياً، والحذف اليدوي يطلب تأكيداً.
4. من الإعدادات: **مكان الحفظ ← تغيير** لاختيار أي مجلد آخر، و**حفظ تلقائي بعد التحميل** لمن يريد أن يذهب الملف إلى المجلد مباشرة.

## الفروق عن نسخة أندرويد

| | أندرويد | ويندوز |
|---|---|---|
| المحتوى الخاص (ستوري انستجرام…) | تسجيل دخول داخل التطبيق | يقرأ تسجيل الدخول من متصفحك: الإعدادات ← الحسابات ← اختر المتصفح (Firefox هو الأوثق؛ Chrome و Edge قد يمنعان القراءة وهما مفتوحان) |
| الترجمة العربية عند رفض المنصة | تُترجم على الجهاز (ML Kit) | **تُرفق الترجمة الأصلية بلغتها** مع تنبيه — لا يوجد محرك ترجمة على الجهاز في نسخة ويندوز |
| استقبال الروابط بالمشاركة | من قائمة المشاركة | لصق من الحافظة أو الاكتشاف التلقائي |
| التحميل في الخلفية | خدمة وإشعار | يستمر ما دامت النافذة مفتوحة؛ عند إغلاقها تتوقف التحميلات مؤقتاً وتُستكمل من حيث توقفت عند الفتح التالي |
| إضافة | — | «حفظ تلقائي بعد التحميل»، «فتح مجلد الحفظ»، «فتح بالبرنامج الافتراضي» |

## تحديث yt-dlp

- **تلقائياً:** بصمت كل 3 أيام.
- **يدوياً:** الإعدادات ← المحرك ← **تحديث**.

إذا توقف موقع عن العمل فأول ما تجرّبه هو زر «تحديث».

## الخصوصية والأمان

- الواجهة تتصل بخادم داخلي يستمع على `127.0.0.1` فقط، وكل طلب يحتاج رمزاً سرياً يُولَّد عند كل تشغيل، فلا تستطيع صفحة ويب أخرى التحكم بالبرنامج.
- الاتصالات الخارجية: المنصة التي تحمّل منها، و GitHub لتنزيل/تحديث المحرك. لا شيء غير ذلك.

## البناء من المصدر

المتطلب الوحيد: **Go 1.24 أو أحدث** (يبني ملف ويندوز من لينكس أو ماك أو ويندوز):

```bash
./build.sh                      # الناتج: dist/Downloader.exe
```

أو مباشرة:

```bash
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w -H windowsgui" -o dist/Downloader.exe .
```

- ملف الموارد `rsrc_windows_amd64.syso` (الأيقونة وبيان التوافق) محفوظ في المستودع. لإعادة توليده بعد تغيير `web/icon.png`: `python3 tools/mkres.py`.
- للتحقق من بنية الـ exe بدون تشغيله: `python3 tools/checkexe.py dist/Downloader.exe`.
- **للتطوير على لينكس/ماك:** `go run . -browser` يشغّل الخادم ويفتح الواجهة في المتصفح (يتوقع `yt-dlp` و `ffmpeg` في PATH).

## بنية المشروع

```
main.go              نقطة التشغيل: الخادم المحلي ثم النافذة
window_windows.go    نافذة WebView2
server.go            واجهة API المحلية + بثّ الأحداث للواجهة
engine.go            yt-dlp: تحليل الرابط واستخراج الجودات، التحميل
direct.go            الروابط المباشرة ووسوم الصفحة
gallery.go           gallery-dl لمنشورات الصور
subtitles.go         اختيار الترجمة وتنظيفها ودمجها بـ FFmpeg
manager.go           طابور التحميلات
stores.go            الإعدادات، المكتبة، السجلّ، الحفظ في الجهاز
tools.go             تجهيز المحرك وتحديثه
sys_windows.go       ما يخص ويندوز: الحافظة، اختيار المجلد، إخفاء نوافذ العمليات
web/                 الواجهة: HTML + CSS + JavaScript (بلا مكتبات خارجية) وخط «تجوّل»
```

## ما تم اختباره قبل التسليم

بيئة البناء لينكس، فاختُبر **الكود نفسه مبنياً للينكس** (المحرك والخادم والواجهة) بمتصفح آلي (Chromium) وبوسائط من خادم محلي:

- تحليل بث HLS بجودتين ومسارَي صوت وترجمتين، وعرض الجودات والخيارات.
- تحميل فيديو مع صوت عربي + ترجمة + قصّ 0:05–0:15 ← ملف مدته 10 ثوانٍ فيه مسار الترجمة.
- رفض ملف الترجمة (خادم يردّ 429) لا يُفشل الفيديو وتُرفق الترجمة الأصلية.
- «صوت فقط» MP3، روابط مباشرة (صورة وفيديو)، حالة الخطأ برسالة عربية.
- الإيقاف المؤقت والاستكمال (بصمة الملف مطابقة للأصل)، الإلغاء مع حذف الملف الجزئي، وحفظ المهام كـ«متوقفة» عند الإغلاق.
- تحميلاتي: بحث، فرز، إعادة تسمية (على القرص أيضاً)، مشغّل الفيديو، تحديد متعدد، والحفظ في `داونلودر\فيديو` و`صور`.
- السجلّ، تنبيه التكرار وحوار التأكيد (مع رابط أُضيف له وسم تتبّع)، اقتراح الرابط المنسوخ.
- الإعدادات: صيغة الصوت، التوازي، تغيير مكان الحفظ والعودة للافتراضي.
- فحص تعارضات البيانات (race detector) أثناء كل ما سبق: لا شيء.
- بنية `Downloader.exe`: تطبيق x64 بواجهة رسومية، فيه الأيقونة بستة أحجام وبيان التوافق.

**لم يُختبر فعلياً:** تشغيل `Downloader.exe` على ويندوز نفسه — لم أستطع تشغيله في بيئة البناء. ويشمل ذلك:
نافذة WebView2، تنزيل المحرك عند أول تشغيل، قراءة الحافظة، نافذة اختيار المجلد، فتح الملفات، إنهاء عمليات التحميل، FFmpeg المرفق (نسخة ويندوز)،
قراءة كوكيز المتصفح، gallery-dl، تحديث yt-dlp، والمنصات الحقيقية (يوتيوب وانستجرام وغيرها).
